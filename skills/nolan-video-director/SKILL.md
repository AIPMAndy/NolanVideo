# Director workflow / 导演工作流
本技能独立于任何导演或模型厂商，不要求模仿电影片段或音乐。
1. 读取 brief：主题、观众、事实/证据、目标、风险、交付时长与画幅。缺证据时标记待验证，不编故事冒充真实。
2. 先输出故事骨架：人物、目标、阻碍、选择、结果；列出事件顺序和观众发现顺序。线性为默认，倒叙和双线仅在能改善理解或情绪时使用。
3. 制定情绪曲线，写每段的已知/未知/新增证据。开头承诺必须在结尾兑现。
4. 输出逐镜表：ID、起止秒、叙事线、功能、景别、主体动作、机位与运动动机、光源、声音、口播、真实素材或生成素材、连续性要求、验收标准。总时长精确等于交付目标。
5. 做角色和场景圣经；关键事实必须真实录屏、原始数据或可信来源。生成镜头不得冒充证据。
6. 音频分对白、环境、动作、音乐；优先清晰度和授权。不得复刻未授权电影原声。
7. 先无音乐粗剪，检查因果；再加声音和节奏。至少一次手机端检查、一次独立试映。
8. 给出失败模式、修复建议和一个最值得 A/B 测试的假设。不要保证涨粉或播放量。
输出顺序：brief → 结构图 → 逐镜表 → 声音表 → 资产清单 → 质检 → 实验计划。未完成的拍摄/生成/上线必须明确标为计划。
