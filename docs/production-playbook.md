# 第一次实战：用一部手机与 AI 完成 60 秒视频

## 0. 准备材料（5 分钟）
选择一个真实、可验证的小问题。准备两个自己拍摄或生成的有差异的镜头、录屏工具、剪辑软件、安静环境。没有素材先拍，不必购买模型订阅。建立 `source/`、`shots/`、`audio/`、`edit/`、`exports/` 文件夹；素材保留原始文件。

## 1. 写导演 brief（10 分钟）
打开工作台，填入主题、目标、障碍、行动、证据。默认选线性，除非先展示结果能帮助观众理解。生成后下载 Markdown。每个镜头替换成自己能拍到的具体动作，不把生成的文字当成拍摄结果。

## 2. 先做一条无音乐样片（20 分钟）
拍一个场景远景、一个人物中景、两个真实操作近景、一个前后对比。录屏前隐藏账号、密钥和客户信息；录制时实际操作一次。将画面按计划粗剪，导入自己录制的口播，删掉没有信息的段落。

## 3. 用 AI 检查分镜（15 分钟）
将下方 Prompt 与真实分镜发送给任意支持文本的模型。它只能根据你提供的证据改进方案；不要要求模型伪造工具测试或真实用户反馈。

```text
你是独立短片的导演和剪辑顾问。以观众体验为第一目标，不要求模仿某位导演的独特画面或原声。
我提供：视频主题、目标观众、人物目标、障碍、实际行动、可验证证据、计划时长、画幅、现有分镜。
先指出故事因果和证据的缺口，再在不虚构事实的前提下提出唯一主方案。
按逐镜表输出：编号、起止秒、观众已知/未知、镜头目的、可见动作、构图与机位、光线、环境声、对白、素材来源、连续性检查。
信息不足时写“待验证”，保留真实步骤，不为炫技而倒叙。每个镜头说明为什么需要；总时长必须相等。
最后给出最可能破坏可信度的三个问题、修复动作和一次可执行的 A/B 测试。
```

## 4. 生成补充镜头（可选）
以同一个参考人物或物件、相同场景为基础生成 1–3 个镜头。Prompt 结构：主体 + 一个动作 + 景别与视角 + 有物理依据的光线 + 空间关系 + 镜头运动及理由 + 前后镜头一致性 + 不可出现的错误。示例：`同一张木桌、同一黑色笔记本、左侧窗光；手将笔记本翻到空白页，固定中近景，镜头不移动，桌面物体位置保持一致，不出现新增文字或额外手指`。任何模型能否稳定遵循这些约束必须实际验证。

## 5. 声音、字幕与导出（20 分钟）
分开对白、环境、动作、音乐四条轨。优先把人声听清，允许留白；使用自己录制或许可明确的声音。字幕只强调必要概念，不遮挡画面信息。竖屏建议 1080×1920、横屏 1920×1080；帧率优先与源素材保持一致。用 FFmpeg 或已有剪辑软件输出，平台限制以实际发布界面为准。

## 6. 试映（10 分钟）
找三名未参与制作的人独立看片，记录他们能否说出问题、方法、结果和下一步。仅改最严重的一项。对比样片时尽量保持素材、受众、时段与长度一致。不要把一次小样本试映当成涨粉保证。

## 7. 七天训练路线
- Day 1：完成一条线性、无音乐的 30 秒作品。
- Day 2：只重剪开头，比较结果先行与线性。
- Day 3：补拍四种景别，每个镜头写明信息作用。
- Day 4：录制环境音、动作音和对白，做声音桥。
- Day 5：生成两个连续补充镜头，检查物理和空间一致性。
- Day 6：完成 60 秒行动/证据双线作品，独立试映。
- Day 7：复盘留存与理解反馈，更新自己的分镜和声音模板。

这些时间是练习建议，不是已测量的制作效率。
